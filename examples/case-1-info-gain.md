# 案例 1：AI 为什么越改剧本越长？——信息增益原则实战

> 同一段网文，普通 LLM 改编 vs Script Vision 适配。核心差异不是文笔，是**克制**。

## 输入（原文，42字）

> 他攥紧了拳头，指节发白。十年了，他终于查到了害死父亲的真凶。

## 普通 LLM 改编

> 【近景。男人的面部特写，眉头紧锁，眼神中燃烧着压抑了十年的怒火。】
> 【特写。他的双手缓缓攥紧，指节因用力而发白，手背青筋暴起。】
> 【特写。他的呼吸变得沉重而急促，胸膛剧烈起伏。】
> 【近景。他缓缓抬起头，目光死死锁定前方，瞳孔中倒映着记忆里父亲临终的画面。】
> 【全景。昏暗的房间里，他孤独地站在窗前，夕阳的余晖将他的影子拉得很长。】
> 男人（声音颤抖，咬牙切齿）：十年了……十年了！我终于查到了……害死父亲的……真凶！

**问题**：
- 42 字膨胀到 200+ 字，5 个镜头标签 + 同义堆砌（攥拳/青筋/呼吸/胸膛全是「愤怒」一个信号）
- 台词被加料：省略号、颤抖、重复「十年了」——原文没有
- 新增「记忆画面」「窗前夕阳」——原文没有

## Script Vision 适配

```text
S01-1 夜 内 老宅书房 ｜00:00-00:04

【近景。男人立于书桌前，双手攥拳，指节发白。】

男人（压抑）：
十年了，我终于查到了害死父亲的真凶。
```

**差异**：
- 42→约 50 字。新增的只有「场景头 + 一句可见化动作」——这是影视化**必需**的最小信息
- 台词逐字保留，零改写
- 「指节发白」是原文信号，保留；「青筋/呼吸/瞳孔」是同义堆砌，丢弃
- 时长 4 秒：14 字台词 ÷ 3.5字/秒 ≈ 4s，时间轴有依据

## 背后的规则

Script Vision 的第一铁律**「适配不是扩写」**：允许更清晰，不允许无意义膨胀。每新增一句描述，必须至少带来一条新的视觉/动作/声音信息——否则不写。

AI 改编最大的毛病，不是不会写，而是太会写。
