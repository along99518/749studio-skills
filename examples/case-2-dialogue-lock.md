# 案例 2：对白是剧本的骨架——为什么禁止 AI「润色」台词

> 台词是剧情载体。改一个语气词 = 改一场戏。

## 输入

> 姜婉婉盯着他，声音发冷：「你为什么骗我？」

## 普通 LLM 改编

> 姜婉婉（眼眶泛红，声音颤抖）：你为什么要一直骗我？为什么！
> 【特写。她手中的杯子滑落，摔碎在地。】

## Script Vision 适配

```text
S03-2 夜 内 公寓客厅 ｜00:47-00:50

【近景。姜婉婉盯着男人，身体僵直。】

姜婉婉（声音发冷）：
你为什么骗我？
```

## 差了什么

| | 普通 LLM | Script Vision |
|---|---|---|
| 台词 | 加了「一直」「为什么！」（原文没有） | **逐字锁定** |
| 情绪 | 眼眶泛红、颤抖（原文是「发冷」） | 保留原情绪「发冷」 |
| 新增事件 | 杯子摔碎（凭空编造） | 零新增 |

普通 LLM 以为自己在「增强戏剧张力」，实际上：
- 下游配音、口型、时长全部按台词计算——台词变了，整条生产链跟着变
- 「发冷」改成「颤抖+泛红」是另一种角色诠释——那是导演和演员的决策，不是适配器的
- 摔杯子是导演的事：现场调度该不该有这个动作，不归文字适配管

## 背后的规则

第三铁律**「对白绝对锁定」**：原始对白 100% 保留，禁止润色、改写、补充、删减、改变语气词。你不是在重新写小说，你是在做影视化适配。
