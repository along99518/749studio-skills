# 案例 3：原文结束，画面也必须结束

> AI 续写是改编中最隐蔽的事故：语气衔接太自然，人眼常常发现不了。

## 输入（小说结尾，原文到此为止）

> 林昭挂断电话，把SIM卡掰成两半扔进江里。她转身离开江堤，没有回头。

## 普通 LLM 改编

> 【远景。林昭的背影消失在江堤尽头的晨雾中。】
> 【黑场。字幕：三个月后。】
> S05-1 日 内 法庭 ｜……
> 林昭坐在旁听席上，看着被告席上的人被押入，嘴角浮起一丝释然的微笑……

## Script Vision 适配

```text
S04-3 晨 外 江堤 ｜01:12-01:18

【近景。林昭挂断电话，取下SIM卡，掰成两半，掷入江水。】

【全景。她转身沿江堤离开，未回头。】
```

## 差了什么

普通 LLM 的续写（「三个月后法庭」）写得很顺——**这正是它危险的地方**：
- 委托方拿到的剧本比原作多了一段，拍摄预算、分镜、配音全部跟着膨胀
- 多出来的内容不是原作者的剧情决策，是模型的「惯性补全」
- 一旦进入生产管线，没人再回头核对原文——错误向后传播

Script Vision 的输出**止于原文最后一段剧情**。原文提到的未来安排只作为剧情信息保留，不得演出来。

## 背后的规则

第二铁律**「原文结束即结束」**（全局禁令）：严禁续写、补全、演绎原文未发生的后续场景、台词、反应或结局。
