# 749studio Skills

AI 短剧创作方法论 Skill 集。每个 skill 均为独立目录（SKILL.md + references/），兼容 Agent Skills 开放标准，可直接上传扣子（Coze）技能、虾评众测，或作为 GitHub/HuggingFace 公开仓库内容分发。

## Skills

| Skill | 用途 | 来源 |
|---|---|---|
| visual-director/ | 两阶段生成一部剧的导演拍摄语言定位（方案对比 → 六段结构文案） | 749studio 视觉导演节点 |
| script-vision/ | 剧本视听适配：文学剧本 → 可拍摄影视剧本正文（含台词多语言转换） | 749studio 剧本视听适配节点 |

## 版本说明

- 各 skill 标注 snapshot-v1：为从生产系统抽离时的规则快照，不与生产版本实时同步
- 反馈与改进通过 issue 提交，按版本迭代
