# 剧本视听适配 · 规则快照（snapshot-v1）

## 可视化强化 — 心理转表演

原文出现抽象心理（「她非常紧张」「他十分愤怒」「他意识到事情不对」）时，转换为可见表演：

- 「她非常紧张」→「【近景。她的手指无意识地攥紧衣角，目光不断扫向门口。】」
- 「他十分愤怒」→「【特写。他的下颌绷紧，盯着对方没有说话。】」

选择 1~2 个最有效的可见信号；同一情绪列 3 个以上身体反应属于同义堆砌，禁止。

## 不擅自增加剧情（硬边界）

视觉化可以增加「表现方式」，不能增加「剧情事实」。

- 允许：把「她很害怕」转成「她攥紧衣角，目光躲闪」
- 不允许：把「她很害怕」改成「她后退两步，撞翻桌子，夺门而逃」（新增剧情行为）

## 台词与动作边界

对白内容只存在于独立对白行；动作描述中不得复述对白内容。

## 叙事节奏档位（可选）

- **标准影视**：保持剧情完整，自然转换，允许环境铺垫/情绪停顿，不为速度过度压缩
- **短剧快节奏**：压缩低价值表达，目标长度约 0.65~0.9 倍；连续动作合并（「走进→关门→坐下→拿手机→看手机→脸色变化」→「他推门进屋，拿起桌上的手机，看到屏幕内容后脸色骤变」）；同一信息只用画面/动作/对白其中一种方式表达；冲突/悬念前置；核心对白保留，仅相同信息的重复对白可合并
- **高密度爆点**：冲突/悬念/异常/线索尽可能前置；连续对白形成攻防关系；减少纯过渡场景；每场承担推进功能；场景结尾形成新信息/问题/危机；不凭空增加反转
- **多集压缩**：压缩目标 40%~60%（参考值）；核心剧情场景只能压缩表达不能删除；关键道具用【特写。道具名。】标记；跨集合并低价值场次，连续编号

所有档位通用铁律：节奏优化 ≠ 改写剧情。原始事件、人物关系、核心因果、结局不改变；不新增剧情事件/反转/人物动机；删减按优先级：必删（重复/语气词/寒暄）→ 可合并（同主题对白/连续动作）→ 谨慎压缩（次要人物细节）→ 禁删（核心冲突/反转/线索对白/主线因果/结局）。
