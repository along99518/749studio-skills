# 爆款开头文案规则（Phase 1 完整规则）

## 步骤 0：核心主角识别（产出任何文案前必须先完成）

通读完整剧本，回答五问：

1. 谁是本集主要视角人物？
2. 谁的行动推动主要剧情？
3. 谁承担主要冲突？
4. 谁是后续故事真正要追随的人？
5. 谁是「解决问题/调查问题/反击问题」的主要行动者？

判定铁律：
- 不能因为某个反派做了最恶劣的事，就把反派当主角
- 不能因为某个受害者遭遇最惨，就把受害者当主角
- 不能因为某个案件最刺激，就把案件本身当叙事主体
- 剧本若存在「新任一把手/空降领导」这类核心人物，优先判断其是否为本集主角

## 叙事组织：必须执行的正确关系

```
主角 → 遭遇/发现重大事件 → 采取行动 → 发现更大黑幕 → 形成更大冲突与悬念
```

禁止的错误关系：反派干了什么 → 受害者有多惨 → 案件有多离谱 → 最后突然出现主角（这本质是「案件简介」，不是主角驱动型爆款开头）。

## 剧本事实锁定（与主角中心同等优先级）

文案中每一句都必须能在剧本正文中找到事实依据。

✅ 允许对原剧本已有信息：压缩、重组、调整叙事顺序、结果前置、强化悬念、选择更高价值的细节、把分散在不同段落的事实组合起来。

❌ 禁止新增原剧本没有明确发生的：人物动作、对白、决定、调查行为、指令、计划、结果、人物关系、公司归属、组织关系、后续剧情。

不得为增强戏剧性补剧情：剧本没写「向省厅发出秘密调查指令」就不能写；没写「敲击手指」就不能为电影感添加；没写「围剿已经布置」就不能提前宣布结果。

### 空间关系锁定

人物所在地点、到达动作和空间关系严格依据原剧本。「抵达义安」不得改写为「刚进市局」。允许语言压缩，不得改变人物实际所在地点和行动节点。

### 人物/组织关系锁定（禁止根据上下文推断关系）

隶属、雇佣、指使、保护、合作、利益关系只能使用原剧本明确建立的关系：

- 「某人参与某事件」≠「某公司的人」
- 「某公司与案件有关」≠「某人受该公司指使」
- 「某领导与某人存在关联」≠「某领导给某人提供保护」
- 「两个案件可能有关」≠「两个案件必然属于同一保护链」

不得把「可能有关」写成「明确属于」。

## 信息上限规则：悬念必须留在「下一步」

爆款开头是「我告诉你一个异常，逼你继续看主角怎么处理」，不是「我把后面发生什么告诉你」。

- 可以暴露：最强事件、主角发现的异常、反派保护链的一部分、主角已开始的行动
- 禁止暴露：主角最终计划、最终围剿/抓捕结果、幕后黑手已被锁定、任何把后续剧情讲完的总结句
- 最后一句必须是悬念钩子（主角即将做什么/发现了什么未解之谜），禁止口号化总结（「正义也许会迟到但不会缺席」式空话）

## 主角主动性（硬规则）

主角不能只是「出现/路过/目睹/听说/恰好发现」。除非剧情本身确实要求偶然目击，必须从剧本已发生的主角行动中选取主动行为。

- 错误：恶霸当街砸店。新局长恰好路过并录下全过程。（主角沦为偶然见证者）
- 正确方向：新局长刚到任。就撞见恶霸当街砸店。（撞见是剧本事实，后续行动只写已发生部分，用悬念句收尾）

## 主角出现位置

不要求第一句就是主角，但主角不能长期缺席：前 1-3 个信息单元内必须建立主角与核心事件的关系。

- 允许：重大事件 → 立即引出主角 → 主角行动
- 禁止：反派介绍 → 受害者惨状 → 案件背景 → 黑幕介绍 → 最后才出现主角

## 爆点扫描（全部来自剧本事实，禁止虚构，必须扫描整集全文）

① 最坏的人（黑心婆婆/嚣张恶霸/黑恶势力/内鬼/贪官）② 最离谱的行为 ③ 利益目的 ④ 极端结果 ⑤ 最大反转 ⑥ 最大打脸 ⑦ 最大悬念

扫描后禁止直接拼接。错误公式：最高爆点+第二爆点+第三爆点=爆款文案。必须执行：

```
核心主角 + 与主角关系最强的爆点 + 主角主动行为 + 最大悬念 = 爆款文案
```

## 四种结构模板（每个候选用不同结构，全部以主角为叙事主体）

| 结构 | 骨架 | 核心问题 |
|---|---|---|
| A 主角撞案型 | 主角到场/上任/初次介入 → 直接撞上极端事件 → 关键反应 → 更大悬念 | 主角一登场就遇到什么大事？ |
| B 主角破局型 | 所有人已把案件压下 → 主角发现异常 → 主动重新调查 → 案件远比表面严重 | 别人不敢碰的事，主角偏偏开始查 |
| C 主角对敌型 | 主角发现反派保护链 → 背后还有更大人物 → 主动向上追查 → 双方即将正面碰撞 | 主角到底准备动谁？ |
| D 主角悬念型 | 重大事件 → 主角发现关键异常 → 异常指向更大黑幕 → 下一步动作形成悬念 | 主角发现了什么别人不知道的东西？ |

## 语言规则

- 结果先行、情绪先行、冲突先行
- 禁止人物介绍式开头（「江若岚，三十三岁，是省公安厅…」→「刚上任的女局长」）
- 禁止环境铺垫开头
- 短句原则：一句话只承载一个信息
- 高频连接词（为了/居然/竟然/结果/谁知/可/直到/本来/原以为/没想到）合理使用不堆砌

## 口播压缩规则（这是口播，不是剧情简介）

最终文案是给短视频配音直接念的。目标不是把背景、人物、案件、反派全部讲完，而是用极少的字建立「主角+极端事件+冲突+悬念」。

- 单句原则：一个 lines 只表达一个核心信息，禁止多事实长句
- 单句长度：一般 4-12 个中文字符，理想 6-10；超过 15 字必须拆分
- 信息取舍优先级：①主角 ②最强冲突事件 ③最关键异常/反转 ④主角主动行为 ⑤最大悬念，其余主动舍弃。宁少三个信息，不多一句废话
- 每个候选只完成一个爆点闭环，禁止信息堆叠式开头（企业荣誉+数十起案件+举报信+硫酸案+警方定性+新局长到任+卷宗+黑幕+围剿…这是剧情梗概）
- 主角中心 ≠ 句句都是主角名字：首次出现后可用「她/他」承接
- 禁止结尾总结剧情：❌「她即将撕开这座城市的黑幕」「一场扫黑风暴即将席卷义安」。悬念必须落在具体问题上（「这伙人是谁的人？」）

## 负面叙事模式（一律禁止）

- ❌ 路过型：新局长恰好路过……
- ❌ 旁观型：新局长目睹了这一切……
- ❌ 最后露脸型：……而这一切，都被刚到任的新局长发现。
- ❌ 反派小传型：一个街头混混，几年后成为企业家……（主角最后一句才出现）
- ❌ 案件摘要型：某老板被毁容……警方定性为纠纷……新局长随后介入……

## 输出前自检（每个候选逐条通过才允许返回）

主角维度：
1. 叙事主体必须是核心主角
2. 主角至少有一个主动行为（且剧本中真实发生）
3. 删除主角后文案仍基本成立？→ 失败（说明实际在讲案件/反派）
4. 主角只是「路过/看到/听说」？→ 换成剧本已发生的主动行为
5. 反派履历写成主体？→ 失败
6. 写成新闻摘要/案件简介/反派小传？→ 失败

事实与信息维度：
7. 每个具体信息逐项核对「是否能在原剧本找到明确依据」；推断出来的关系/位置/细节 → 删除或换成有依据的表达
8. 提前宣布最终计划/围剿结果/幕后黑手已锁定？→ 失败
9. 最后一句是悬念钩子还是口号总结？口号 → 失败
10. 能让观众产生「我要看主角接下来怎么处理」的追看欲？

口播长度维度：
11. lines 合计字数是否落在时长硬区间（20S：50-65 字 / 30S：75-95 字）？两头都算失败
12. 超过 15 字的长句？→ 拆句。读起来像剧情简介？→ 只留一个核心爆点闭环
13. 拆句后主角仍是叙事发动机、事实全部有据？

## 刷新去重规则（用户提供历史候选的 hooks 时启用）

- 禁止同一核心事件换措辞重写（「举报人被泼硫酸」→「实名举报的人遭到硫酸袭击」属无效刷新）
- 必须尽量改变核心事件/核心人物/情绪入口/结构/悬念
- 若剧情已无新的重大事件，允许重新使用高价值事件但必须改变结构和切入角度
